# GitCheck-Mobile-App
Мобильное приложение, разработанное для взаимодействия с ресурсами Github.

### Требования к окружению
#### Для пользователей
* Операционная система: 
    - мин: Android 8.0 (API level 26)
    - макс: Android 16.0 (API level 36)
* Архитектура процессора:
    - arm64-v8a
    - armeabi-v7a
* Наличие интернет соединения для запросов к API Github

#### Для разработчиков
* Среда разработки: Android Studio Meerkat | 2024.3.1
* Версия Java (JDK) для сборки: Amazon Corretto 17
* Инструменты сборки (Gradle): 
    - Gradle Wrapper: 8.11.1
    - Android Gradle Plugin (AGP): 8.9.1
